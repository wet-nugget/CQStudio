# CQStudio beginner launch guide

The current deployment path is **browser-only, from the GitHub repository**.

Open [the complete GitHub → Vercel + Supabase walkthrough](GITHUB-DEPLOYMENT.md).
It replaces the earlier local-folder setup procedure and includes every dashboard
field, the two environments, email, administrator invitation, monitoring and
real-service acceptance. No `.env.local`, local header preparation or terminal
command is required from the repository owner.

Start with [START-HERE.md](../START-HERE.md) and gather owner decisions using
[the input checklist](../setup/OWNER-INPUTS.example.md). The checklist can be
answered in a private GitHub issue without downloading a file; never put secrets
in issues or commits.

For optional development on a computer, use [local development](LOCAL-DEVELOPMENT.md).
For the final sign-off, use [the launch checklist](LAUNCH.md) and
[installer acceptance record](../setup/ACCEPTANCE.md).
