# CQStudio AI Lesson Context

## What CQStudio is

CQStudio (Offline Class & Quiz Studio) is a browser-only study app. Lessons belong to a class and are imported from Markdown files or pasted into the lesson editor. The app stores lesson text and progress in that browser's localStorage; it has no backend or synchronization.

## What a lesson is

A lesson is structured study content with a title and Markdown body. Learners can open a lesson, set its status (Not started, In progress, Completed), rate confidence from 1–5, and write a reflection. Class Detail summarizes completed lessons. Materials / Notes are separate quick notes, links, attachments, or reference files; quizzes are assessments.

## Supported lesson Markdown

The lesson renderer supports this safe subset:

- Headings using one through six `#` characters followed by a space.
- Paragraphs (each non-empty line is rendered as a paragraph).
- Bold with `**text**`, italic with `*text*`, and inline code with `` `code` ``.
- Bulleted lists using `-`, `*`, or `+`; numbered lists using `1.` or `1)`.
- Blockquotes using `>` at the start of a line.
- Fenced code blocks using triple backticks.

Do not rely on tables, links, images, nested lists, task lists, HTML, scripts, or other advanced Markdown: they are not supported as lesson formatting. HTML is escaped and shown as text. Do not include arbitrary HTML or JavaScript.

## Recommended lesson structure

```md
# Lesson title

## Learning goals
- State what the learner should understand.
- Use observable, focused outcomes.

## Key ideas
Explain one concept at a time in short paragraphs.

## Example
> Include a concise, accurate example or memorable rule.

## Check your understanding
1. Ask a recall question.
2. Ask the learner to explain a relationship.

## Summary
Restate the most important ideas.
```

## Complete example lesson

```md
# Cell Structure and Function

## Learning goals
- Identify the main parts of a typical cell.
- Explain how organelles contribute to cell function.

## Key ideas
The cell is the basic structural and functional unit of life. Cells contain structures that carry out specialized tasks.

**The nucleus** stores genetic information. *Mitochondria* release usable energy from food molecules.

## Example
> A cell works like a coordinated system: each component has a role, and the parts work together.

## Check your understanding
1. Which organelle stores genetic information?
2. Why do cells need specialized structures?

## Summary
Cells are organized systems. The nucleus stores genetic information, while mitochondria help release usable energy.
```

## Writing guidance

- Keep one main idea per section and use descriptive headings.
- Prefer short paragraphs, precise terms, and concrete examples.
- Distinguish established facts from examples or simplifications.
- Write learning goals and review questions that can be answered from the lesson.
- Avoid unsupported Markdown syntax and arbitrary embedded code.
- Do not invent CQStudio features, renderer behavior, or syntax beyond this document. If a capability is uncertain, omit it rather than claim support.

## Progress and reflection

Lesson status is independently set to Not started, In progress, or Completed. Confidence is a 1–5 self-rating (0 means not rated), and reflection is learner-authored text. These values are saved with the lesson locally; progress status does not automatically change as the learner reads.
